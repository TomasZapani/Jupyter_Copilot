# Jupyter Copilot

Jupyter Copilot es un asistente LLM local para Jupyter Notebook, desarrollado con Python, FastAPI y HTML.  

> **Nota:** Este proyecto está en proceso de desarrollo.

## 🚀 Tecnologías

- **Backend**: Python + FastAPI  
- **Frontend**: HTML  
- **Integración**: Jupyter Notebook

## ⚙️ Instalación

1. Clona el repositorio:  

   ```bash
   git clone https://github.com/TomasZapani/Jupyter_Copilot.git
   cd Jupyter_Copilot
   ```  

2. Instala las dependencias:  

   ```bash
   pip install -r requirements.txt
   ```  

3. Inicia el servidor:  

   ```bash
   uvicorn main:app --reload
   ```  

4. Conecta el asistente desde Jupyter Notebook.
